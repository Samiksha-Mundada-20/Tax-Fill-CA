## PROJECT OVERVIEW
Create a full-stack web application that allows Indian taxpayers to upload Form 16 PDFs, automatically extract data using Mistral OCR, calculate tax under both new and old regimes, generate CBDT-compliant ITR-1 JSON files, and guide users through manual e-filing portal upload.

## LEGAL & COMPLIANCE REQUIREMENTS

### 1. Income Tax Act 2025 Compliance
- Implement both tax regimes per Section 115BAC (new regime is default)
- New Regime Slabs FY 2025-26:
  * ₹0-4 lakh: 0%
  * ₹4-8 lakh: 5%
  * ₹8-12 lakh: 10%
  * ₹12-16 lakh: 15%
  * ₹16-20 lakh: 20%
  * ₹20-24 lakh: 25%
  * Above ₹24 lakh: 30%
  * Standard deduction: ₹75,000 for salaried
  * Section 87A rebate: Full rebate if taxable income ≤ ₹12 lakh

- Old Regime Slabs FY 2025-26:
  * ₹0-2.5 lakh: 0% (below 60 years)
  * ₹2.5-5 lakh: 5%
  * ₹5-10 lakh: 20%
  * Above ₹10 lakh: 30%
  * Standard deduction: ₹50,000 for salaried
  * Section 87A rebate: Full rebate if taxable income ≤ ₹5 lakh

- Health & Education Cess: 4% on total tax + surcharge
- Surcharge (New Regime): 10% (₹50L-₹1Cr), 15% (₹1-2Cr), 25% (₹2-5Cr), 30% (above ₹5Cr)

### 2. Deductions (Old Regime Only)
Implement these deductions with exact limits:
- Section 80C: ₹1,50,000 limit (EPF, PPF, ELSS, LIC, home loan principal, tuition fees)
- Section 80D: ₹25,000 (self/family below 60), ₹50,000 (senior citizens), max ₹1,00,000 combined
- Section 80G: 50% or 100% of donations (no fixed cap, institution-dependent)
- Section 80TTA: ₹10,000 on savings account interest (non-seniors)
- Section 80TTB: ₹50,000 on interest income (seniors 60+)
- Section 24(b): ₹2,00,000 on home loan interest (self-occupied, old regime only)
- Section 80CCD(1B): Additional ₹50,000 for NPS Tier I (over and above 80C)
- HRA Exemption (Section 10(13A)): Minimum of:
  1. Actual HRA received
  2. Rent paid − 10% of (Basic + DA)
  3. 50% of (Basic + DA) for metros (Delhi, Mumbai, Kolkata, Chennai) OR 40% for non-metros
- LTA (Section 10(5)): 2 domestic journeys per 4-year block (2026-2029), exemption capped at economy airfare or AC first-class rail by shortest route

### 3. DPDP Act 2023 Compliance
- Implement granular consent management before processing PAN/Aadhaar/financial data
- Display privacy notice with data purposes, retention periods, user rights
- Data retention policy: Delete uploaded documents after 1 year unless user opts to save

- Publish grievance redressal contact (email/phone)
- Execute data-processing agreements with Mistral AI, AWS, and all sub-processors
- Document all data flows (create data-flow diagram)
- Allow users to download/delete their data (right to access, right to erasure)

### 4. RBI Data Localization (if processing payments)
- Store all payment data (credit/debit cards, UPI, wallets) ONLY in AWS Mumbai/Delhi regions

- Create data classification labels: payment_data, KYC_data, PII, financial_data

### 5. IT Act 2000 Cybersecurity

## ITR FILING INTEGRATION

### ITR Forms Supported (AY 2026-27)
- ITR-1 (Sahaj): Salaried/pensioners, income ≤ ₹50 lakh, one house property, no capital gains
- ITR-2: Capital gains, foreign assets, multiple house properties (no limit)
- ITR-3: Business/profession income (freelancers, consultants)
- ITR-4 (Sugam): Presumptive business income (Section 44AD/44ADA), income ≤ ₹50 lakh

### CBDT JSON Schema Integration
- Download official JSON schemas from incometax.gov.in → Downloads → AY 2026-27:
  * ITR-1: Released May 15, 2026 (v1.0)
  * ITR-2: Released May 26, 2026 (v1.0)
  * ITR-3: Released June 18, 2026 (v1.0), updated June 30 (v1.1)
  * ITR-4: Released May 15, 2026 (v1.0)
- Store schemas in `/schemas/` folder
- Implement JSON schema validation using `jsonschema` library
- Implement CBDT validation rules (Category A = blocking errors, Category D = warnings):
  * PAN format: ^[A-Z]{5}[0-9]{4}[A-Z]{1}$
  * 80C limit: Cannot exceed ₹1,50,000
  * Tax payable: Cannot be negative
  * IFSC code: 11 characters (e.g., SBIN0001234)
  * Bank account validation
- Monitor CBDT portal weekly for schema version updates (schemas change mid-season)

### Filing Workflow (No Official API)
Since Income Tax Department has no public REST API:
1. Generate CBDT-compliant JSON file programmatically
2. Provide download link to user
3. Guide user to manual upload:
   - Visit incometax.gov.in → e-File → Income Tax Returns → File ITR
   - Select AY 2026-27, ITR form type, Filing Mode: "Upload JSON"
   - Upload generated JSON file
   - Verify pre-filled data (salary, TDS should match Form 16/26AS)
   - Submit return
   - E-verify via Aadhaar OTP / Net Banking / DSC

## MISTRAL OCR INTEGRATION

- Form 16 Part B: Gross salary, HRA/LTA exemptions, 80C/80D deductions, net taxable income

- Home loan statement: Interest paid (Section 24b), principal repaid (80C)
- Health insurance premium: Premium amount, policy number (80D)

- Handwriting support: Handle handwritten rent receipts, investment certificates
- 170-language support: English + Hindi + regional languages
- Pricing: $4 per 1,000 pages ($0.004/page); 50% discount for batch API

### Self-Hosting Option (for data residency)

## DATABASE SCHEMA (PostgreSQL)

```sql
-- Users table
CREATE TABLE users (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    pan VARCHAR(10) UNIQUE NOT NULL,
    name VARCHAR(255) NOT NULL,
    email VARCHAR(255) UNIQUE NOT NULL,
    phone VARCHAR(15),
    password_hash VARCHAR(255) NOT NULL,
    date_of_birth DATE,
    is_senior_citizen BOOLEAN DEFAULT FALSE,
    created_at TIMESTAMP DEFAULT NOW(),
    updated_at TIMESTAMP DEFAULT NOW()
);

-- Consent table (DPDP compliance)
CREATE TABLE user_consents (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    user_id UUID REFERENCES users(id) ON DELETE CASCADE,
    consent_type VARCHAR(50) NOT NULL,  -- 'ocr_processing', 'data_storage', 'tax_calculation'
    granted BOOLEAN NOT NULL,
    granted_at TIMESTAMP DEFAULT NOW(),
    revoked_at TIMESTAMP,
    UNIQUE(user_id, consent_type)
);

-- Documents table
CREATE TABLE documents (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    user_id UUID REFERENCES users(id) ON DELETE CASCADE,
    document_type VARCHAR(50) NOT NULL,  -- 'form16', '26as', 'ais', 'rent_receipt', 'investment_proof'
    file_name VARCHAR(255) NOT NULL,
    s3_key VARCHAR(500) NOT NULL,  -- AWS S3 Mumbai key
    ocr_result JSONB,  -- Mistral OCR output (fields, bounding boxes, confidence scores)
    uploaded_at TIMESTAMP DEFAULT NOW(),
    auto_delete_at TIMESTAMP,  -- DPDP: auto-delete after 1 year
    deleted_at TIMESTAMP
);

-- Tax calculations table
CREATE TABLE tax_calculations (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    user_id UUID REFERENCES users(id) ON DELETE CASCADE,
    assessment_year VARCHAR(9) NOT NULL,  -- '2026-27'
    gross_salary DECIMAL(15,2) NOT NULL,
    other_income DECIMAL(15,2) DEFAULT 0,
    deductions_80c DECIMAL(15,2) DEFAULT 0,
    deductions_80d DECIMAL(15,2) DEFAULT 0,
    deductions_80g DECIMAL(15,2) DEFAULT 0,
    home_loan_interest DECIMAL(15,2) DEFAULT 0,
    hra_received DECIMAL(15,2) DEFAULT 0,
    rent_paid DECIMAL(15,2) DEFAULT 0,
    is_metro BOOLEAN DEFAULT FALSE,
    new_regime_tax DECIMAL(15,2) NOT NULL,
    old_regime_tax DECIMAL(15,2) NOT NULL,
    recommended_regime VARCHAR(10) NOT NULL,  -- 'new' or 'old'
    calculated_at TIMESTAMP DEFAULT NOW()
);

-- ITR filings table
CREATE TABLE itr_filings (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    user_id UUID REFERENCES users(id) ON DELETE CASCADE,
    assessment_year VARCHAR(9) NOT NULL,
    itr_form VARCHAR(5) NOT NULL,  -- 'ITR-1', 'ITR-2', etc.
    json_payload JSONB NOT NULL,  -- Full ITR JSON
    s3_key VARCHAR(500) NOT NULL,  -- AWS S3 Mumbai key for JSON file
    cpc_ack_number VARCHAR(50),  -- Acknowledgment number from IT portal (if user provides)
    filed_at TIMESTAMP DEFAULT NOW(),
    verification_status VARCHAR(20) DEFAULT 'pending'  -- 'pending', 'verified', 'defective'
);

-- Audit logs table (IT Act 2000 compliance)
CREATE TABLE audit_logs (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    user_id UUID REFERENCES users(id) ON DELETE SET NULL,
    action VARCHAR(100) NOT NULL,  -- 'login', 'upload_document', 'calculate_tax', 'generate_itr'
    resource_type VARCHAR(50),  -- 'document', 'tax_calculation', 'itr_filing'
    resource_id UUID,
    ip_address INET,
    user_agent TEXT,
    created_at TIMESTAMP DEFAULT NOW()
);

-- Indexes for performance
CREATE INDEX idx_users_pan ON users(pan);
CREATE INDEX idx_documents_user_id ON documents(user_id);
CREATE INDEX idx_documents_auto_delete ON documents(auto_delete_at) WHERE deleted_at IS NULL;
CREATE INDEX idx_tax_calculations_user_id ON tax_calculations(user_id);
CREATE INDEX idx_itr_filings_user_id ON itr_filings(user_id);
CREATE INDEX idx_audit_logs_user_id ON audit_logs(user_id);
CREATE INDEX idx_audit_logs_created_at ON audit_logs(created_at);
```
